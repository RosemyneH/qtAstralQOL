# Changelog

Versions are `1.1` through `1.20`, then `2.0`.


## [1.4](https://github.com/RosemyneH/qtAstralQOL/releases/tag/v1.4) (2026-09-07)

### Features

* Callboard: Board button, click to turn in, shift-click to share, custom scrollbar
* Table view bundles LFG, Elite, and Rare; elite rows show zone; names on hover; check only when done
* Gem extraction skip list with named presets; Disenchant from the level-up reward popup
* Character gem dock defaults off when AllStats is loaded
* Gem toasts use Astral gain popups and ElvUI Transparent skinning


## [1.3](https://github.com/RosemyneH/qtAstralQOL/releases/tag/v1.3) (2026-09-07)

### Features

* Party callboard docks to the quest log, scrolls, and syncs accepted dailies over the group
* Party and Table views; LFG shows dungeon short plus boss; Elite shows short zone plus NPC
* Completion checkbox, progress on hover, tokens on the right
* Character and inspect gem docks use compact horizontal socket rows


## [1.2](https://github.com/RosemyneH/qtAstralQOL/releases/tag/v1.2) (2026-09-07)

No addon changes. Version bump only.
